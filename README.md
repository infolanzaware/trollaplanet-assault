# TrollaPlanet Assault

Gioco browser in stile vector graphics (ispirato al cabinato Atari Star Wars del 1983).

## Come giocare
- Apri `index.html` in qualsiasi browser moderno.
- Muovi il mouse (o trascina il dito su mobile) per mirare.
- Clicca / tieni premuto SPACE / tocca lo schermo per sparare.
- Distruggi i troll di internet (verdi) e i satelliti spia (rossi).
- Schiva i proiettili nemici.
- Raggiungi TrollaPlanet e distruggi il Core!

## Controlli
- Mouse / Touch: mira
- Click / SPACE / Touch: spara
- Funziona online e offline (file autonomo).

Creato per Lanzaware Movie Production.
